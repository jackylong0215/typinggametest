# 倉頡小島 · 冒險基地

繁體中文倉頡學習遊戲。原生 HTML、CSS、JavaScript 和 Node.js，無需安裝套件。

## 啟動、匯出、測試

- Node.js 18 以上，執行 `npm start`，預設 port 3000，可透過 `PORT` 覆寫。
- `npm run export` 產生 `dist/倉頡小島試玩.html`，也可用 `npm run export -- /指定路徑/試玩.html` 匯出。
- `npm test` 執行 14 項資料及狀態測試：原始字碼表、題目與教材碼、筆畫分組、字形取景、完整難度題庫、錯字簿掌握規則及版本隔離。

## 四級難度

適用拆字工房、生存挑戰、極速航線：

| 難度 | 題庫 | 生存每字時限 | 生命 |
|---|---|---|---|
| 萌芽探險 | 24 個原形字／基本字根 | 20 秒 | 5 |
| 森林學徒 | 入門常用字，最多三碼 | 15 秒 | 4 |
| 拆字高手 | 常見字、複合字及特殊取碼 | 10 秒 | 3 |
| 全字庫大師 | 所選碼表中的全部字，五代共 20,840 字 | 7 秒 | 3 |

五代預設使用用戶提供的 `data/cangjie5_single_main.json`，另可選三代。不同版本的判題、錯字及高分分開記錄。最高難度五代沒有過濾罕見字，每個字都有機會被抽到。初階的原形字可直接練，不依賴輔助字形參考圖。

## 玩法

- **字根森林**：原圖的基本／輔助字形，可按 24 個字根家族或大組別溫習，完成 10 題。
- **拆字工房**：按所選難度練習，完成 10 題。
- **標色教室**：3,500 個原字的彩色地圖，可從清單選字，逐步看部件和取碼；進入後會繼續抽取標色字。
- **生存挑戰**：取代舊字雨。每題在時限內按空白鍵送出；答錯或超時扣一顆生命，簡短顯示正確碼後繼續，生命歸零結算。沒有整局時間上限。
- **極速航線**：延長至 180 秒。錯碼可修正，時間歸零結算。
- **難字形與特殊規則**、**標點符號學堂**：保留有教學解說的定向練習。

實體鍵盤及模擬鍵盤皆可操作，支援刪除和空白鍵。每碼有即時回饋；一般練習連錯兩次提示字根，三次顯示完整碼。答對後自動跳題，標色題保留較長時間；查表暫停計時。挑戰中的「結束並看回顧」可提前結算。

## 成績、錯題及錯字簿

答對得 10 分，三連擊起另加 5 分。最高分按模式、版本及難度分開保存，每次得分即更新，重玩不會清空最高紀錄。完成回合另外保存星星、準確率及歷史紀錄。

每次送出錯碼，或在生存挑戰中超時，立即加入錯字簿；同字不重複開卡，會累計錯誤次數。結算顯示本局打錯的字、送出的碼、超時紀錄及正確取碼，即使後來答對仍保留本局回顧。

每個錯字在任意練習／挑戰中累計答對兩次後移除，無需連續答對，途中再錯不會抹去已累積的掌握次數。可從錯字簿開始專項練習。資料保存在目前瀏覽器 localStorage，三代、五代、符號及輔助字形分開記錄；未提供雲端同步。

## 原字標色資料

3,500 字使用 Hanzi Writer Data／Make Me A Hanzi 的原始筆畫輪廓，保持部件原位，支援逐步選看、重播及全字標色。每個分組的取碼和輪廓索引都經資料測試核對；部件取碼順序與寫字筆順不同。其餘字提供正確碼，不假裝已完成筆畫分組。

來源與 Arphic Public License 見 `THIRD_PARTY_NOTICES.md` 及 `licenses/ARPHICPL.TXT`，授權亦包含在單檔試玩版中。

## 原圖字根表

手繪近似字形已撤除。參考圖包含 127 格（B 組 11 格）；`auxiliary-data.js` 保存每格取景框。瀏覽器中在字根圖鑑按「載入參考原圖」選擇完整 `cj-table-kll.png`，即直接顯示原圖字形；可下載含原圖的獨立版本。SVG 明確使用 `overflow:hidden`，防止整張圖溢出疊放。

原圖檔尚未由雲端取得，取景邊界未完成實圖像素級核對。匯入、裁切、分組、練習及內嵌匯出已使用測試圖片驗證。

## 標點符號

20 種標點包含用途及例句。採固定的 ibus-table 三代 Z 開頭符號碼（例如逗號 ZXAB、句號 ZXAD），不按中文字形拆碼，也不代表所有作業系統輸入法的快捷方式。

## 部件標色修正

池的也分成心、木；家的豕分成一、尸、人。春的中撇、米的中豎使用原始輪廓配合互補裁切區域，分別標成兩個字根，不改寫筆畫形狀。春的第三橫屬大形，米的中豎上段屬火的小形。想的相作字首只取木、山，省略的目上半部分留灰。宇、守、完、字、子、村、朵、李均改成逐碼分色；好、孔、孟、付的共用子／寸部件同步更新。教室縮圖和逐步動畫共用同一套分段繪製，避免兩處顯示不一致。

本次標色更新：完的第三碼厂包含第二橫與左撇，最後只有乚標為山；池的也分為豎彎鉤（心）與橫折鉤加中豎（木）。新增龍、興、園、書、齊，省略的取碼筆畫保留灰色；五碼字使用五種獨立顏色。


## 三千五百字標色資料與檢查

五代標色庫恰好 3,500 字（原有 116 字＋生成 3,384 字），優先收錄常用字。每個字碼獨立一色，未取碼筆畫留灰；長筆畫可分成多段，例如事、重。龍只將亠取卜，末碼匕的橫畫與豎彎鉤同色；完的厂與乚分開。包及抱、泡等字的內口與彎鉤亦分段標色。

教室支援中文字／倉頡字碼搜尋，每頁 48 字。五代與三代碼不同時，三代不沿用五代標色；教室與抽題只顯示符合當前版本的示範，其他題仍可查看所選版本的正確碼。

`colour-library.js` 由 `scripts/build-colour-library.py` 生成。`data/colour-source.json` 保存已選字與必要部件的原始輪廓、IDS 筆畫對應、字根模板及來源雜湊；`data/colour-audit.json` 保存新增字每一碼的部件來源與筆畫區域。生成不依筆畫數平均切段：先沿 IDS 對應筆畫，再使用明確字根模板，最後按用戶五代碼表選取有效字根；不能唯一定位的跨部件情形不收錄。相鄰重複字根依首／尾取碼位置處理。

重建：`python3 scripts/build-colour-library.py`。檢查：`npm test`。瀏覽器檢查在已安裝 Playwright／Chromium 的環境執行 `node scripts/check-colours-browser.cjs`（先啟動 `npm start`；可用 `COLOUR_TEST_URL` 指定網址，或 `COLOUR_TEST_FILE` 指定獨立 HTML）。它會逐字檢查全部標色步驟、原始輪廓、顏色與裁切區域，並輸出每批 100 字的對照圖至 `dist/colour-review/`。

資料檢查與逐批看圖有助發現錯誤，不等於專家逐字認證。若修正部件模板，應重建整個資料庫並重新檢查受影響字，不能只改字碼讓測試通過。


### 用戶新參考圖

丞、丑、並、亟、亞、伊、劉、厮、囊、募、巔、奧均依新參考圖重建部件，另提供厮的繁體廝。教室按「查看新參考字」可集中練習。參考圖不同的背景與配色不直接使用，所有字統一採本遊戲的白底 SVG、逐碼分色及省略筆畫灰色。

巔的上游原始字形使用眞的匕頭變體；用戶提供十頭真。此字以巅中十頭真的原始十筆輪廓，組合巔原有山及繁體頁輪廓，不縮放或手繪筆畫。來源及組合索引記錄於 `contour_adaptations`、`reference_original_graphics`，並由測試逐筆比對。

圖片匯出：先執行 `node export.js`，再執行 `node scripts/export-reference-images.cjs`。逐字 PNG 位於 `dist/reference-glyphs/`；`dist/新增標色參考圖.zip` 包含十三張圖（十二個參考字及廝變體）。

### 共用部件修正（2026-10-21）

依用戶新參考統一修正隹、門、幺、乍、力、斤及相關字。隹只取亻與右下土；門的 N 只取右上日形以下的豎鉤，上方日形留灰；幺的 V 只取第一撇折；乍採 HS。斤的兩撇屬 H，橫畫屬 M，直豎屬 L；取 ML 時兩撇留灰。力的 S 由交接處右方起標，保留折鉤尾。七、工、乙獨立分別取 JU、MLM、NU，作輔助字形仍分別取 P、M、N。

原始上傳五代檔保持不變；用戶指定的教學修正獨立記錄於 `code_corrections`，套用於執行時答案與標色資料。乍系列的 22 個字逐一與三代參考碼核對，教學模式採同一 HS 取形。最新對照圖見 `dist/本次修正標色對照.png`。

本輪由 1,000 擴充到 3,500 字，增加 2,500 字，保留原有 1,000 個標色模型。新增虫、酉、皿、欠、牛、足、衣、魚、鳥、雨的明確部件模板，優先選繁體候選字；完整庫亦含部分簡體字。每頁 48 字，五代共 73 頁。

圖像檢查：`node scripts/check-colour-pixels.cjs` 會把每字 SVG 實際轉成 256px 圖像，確認每個字碼都有可見色塊；`dist/colour-review/pixel-audit.json` 保存逐字色塊像素數。這可發現空白／完全裁走的標色，不能取代人工判讀取形。

## 網站發佈與效能

執行 `npm run build` 產生 `site/`，為完整靜態網站；可放在 GitHub Pages 子目錄。`.github/workflows/pages.yml` 在 main 更新後測試、建置與部署。若倉庫尚未啟用 Pages，先在 Settings → Pages → Build and deployment 選擇 GitHub Actions。

網站首頁使用小型字形索引，3,500 字原始輪廓按需載入 71 組。首頁不下載完整 colour-library.js，不依賴外部字體；靜態檔以內容雜湊命名。`npm start` 自動建置，Node 伺服器支援 Brotli／gzip 與快取。原本的單檔 HTML 仍是全字庫離線包，檔案較大；線上網站使用分組版本。

`node scripts/check-site-browser.cjs` 測試首頁不載入字形分組、慢速網路、載入失敗重試、全部字形可載入及 Pages 子目錄。最新測量：150 KB/s、100ms 延遲、4 倍 CPU 降速下，首頁教材可操作約 2.7 秒（此環境測量）。報告存於 `dist/site-performance.json`。

門部更新：依用戶矩形示意圖，右側日形包含右豎均留灰，只有日形以下的豎鉤取 N。共用門模板套用至 41 個標色字，關另有直接模板並同步修正。

小：獨立輸入取 NC，豎鉤為弓、左右兩點為金；尖等字內的小形仍取 F。字根輔助形練習與獨立中文字模型分開判定。
