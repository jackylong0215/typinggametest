# 倉頡小島 · 冒險基地

繁體中文倉頡學習遊戲。原生 HTML、CSS、JavaScript 和 Node.js，無需安裝套件。

## 啟動、匯出、測試

- Node.js 18 以上，執行 `npm start`，預設 port 3000，可透過 `PORT` 覆寫。
- `npm run export` 產生 `dist/倉頡小島試玩.html`，也可用 `npm run export -- /指定路徑/試玩.html` 匯出。
- `npm test` 執行 59 項資料及狀態測試：原始字碼表、題目與教材碼、筆畫分組、字形取景、完整難度題庫、錯字簿掌握規則及版本隔離。

## 四級難度

適用拆字工房、倉頡勇者傳、極速航線：

| 難度 | 題庫 | RPG 作答方式 |
|---|---|---|
| 萌芽探險 | 24 個原形字／基本字根 | 四選一，35 秒 |
| 森林學徒 | 入門常用字，最多三碼 | 五色圖引導輸入，25 秒 |
| 拆字高手 | 常見字、複合字及特殊取碼 | 輸入字碼，18 秒 |
| 全字庫大師 | 所選碼表中的全部字，五代共 20,840 字 | 輸入字碼，14 秒，敵方每三回合可干擾 |


五代預設使用用戶提供的 `data/cangjie5_single_main.json`，另可選三代。不同版本的判題、錯字及高分分開記錄。最高難度五代沒有過濾罕見字，每個字都有機會被抽到。初階的原形字可直接練，不依賴輔助字形參考圖。

## 玩法

- **字根森林**：原圖的基本／輔助字形，可按 24 個字根家族或大組別溫習，完成 10 題。
- **拆字工房**：按所選難度練習，完成 10 題。
- **標色教室**：10,000 個原字的彩色地圖，可從清單選字，逐步看部件和取碼；進入後會繼續抽取標色字。
- **倉頡勇者傳**：取代生存挑戰的回合制 RPG。三十層高塔，每層一隻敵人，第 5／10／15／20／25 層是精英，第 30 層是蝕字魔龍王；噬晶黏怪、裂眼夜蝠、焰牙魔狼、咒岩石像、棘翼飛龍與鐮足蟲魔有不同外形及 Lv.，生命值隨等級提高，需要多次攻擊才能擊敗。
- **極速航線**：延長至 180 秒。錯碼可修正，時間歸零結算。
- **難字形與特殊規則**、**標點符號學堂**：保留有教學解說的定向練習。

### RPG 戰鬥規則

先選招式，再答題。原形／入門／進階／大師字基礎傷害為 18／24／32／42，以最低所屬題庫判定，並加入最多 6 點連擊加成。「字根斬」是普通攻擊；「五色連擊」需兩格能量，傷害約為普通攻擊的 1.92 倍；「守護結界」傷害約為 2/3，並擋下最多 12 點敵方反擊傷害。答對才消耗招式能量並回復一格，最多存三格。敵人存活便會反擊，答錯／超時只受到敵方攻擊。每隻普通敵人被擊敗後，前進時回復最多 14 HP；精英回復 20 HP。

每局開局有一瓶補血藥（＋35 HP）、一個沙漏（本題＋8 秒）、一面提示鏡（初級排除兩項；有五色圖時只突出部件，否則顯示首碼）。最高難度敵人每三回合輪流準備迷霧（下一題暫藏鍵盤字根五秒）、封印（下一題不能使用連擊）、急風（下一題少三秒）。輸入不會被打亂或刪除。查字根表及頁面切至背景時暫停倒數。每回合有秒數及進度條倒數，最後五秒變色；超時即受到攻擊並收錄錯字。答對後播放字根斬、五色連擊或結界動畫及敵方反擊，三秒後自動前進；答錯／超時保留四秒回顧後自動前進。通關／失敗亦會自動顯示成績，可按按鈕提前繼續。

所有 RPG 輸入難度均有五色拆字過渡：第 1–10 層顯示標色圖，逐碼輸入會突出下一個部件；第 11–20 層顯示顏色和步驟編號，由學生自行點選部件觀察；第 21–30 層預設獨立作答，可按需展開五色提示。圖片與標色教室共用原字輪廓、顏色及互補裁切，不重畫字形；只選與所選版本取碼完全相符的入門字。字形資料按需載入，載入完成才開始本回合倒數，失敗可重試或改用原字；離開／結算後不會被遲到的請求重新開啟。第四級前二十層從有相符標色圖的字中練習，第二十一層起回到完整碼表，仍保留所有字出題的可能。拆字工房、特殊規則、極速航線及錯字加強也有四題漸進熱身：前兩題用圖引導取碼順序，接著兩題自行看圖找字根，之後收起圖片。若指定題庫沒有標色資料，會明示使用入門例字熱身，再返回原題庫；標色教室本身維持完整教學圖片。

RPG 分數、星星、版本和難度最高分、歷史及錯字簿沿用學習紀錄。完成、失敗、手動結算或答題後離開時只記錄一次；錯字答對兩次移出。執行 `node scripts/check-rpg-turns.cjs` 可驗證真實倒數、自動換回合、三種出招動畫及失敗自動結算；執行 `node scripts/check-rpg-browser.cjs` 可驗證完整三十層通關、選擇題／模擬鍵盤、道具、暫停、超時、最高難度技能、手機版面及其他模式。

實體鍵盤及模擬鍵盤皆可操作，支援刪除和空白鍵。每碼有即時回饋；一般練習連錯兩次提示字根，三次顯示完整碼。答對後自動跳題，標色題保留較長時間；查表暫停計時。挑戰中的「結束並看回顧」可提前結算。

## 成績、錯題及錯字簿

一般模式答對得 10 分，三連擊起另加 5 分；RPG 每次答對得 20＋連擊數×5 分，擊敗敵人再得 Lv.×30 分。最高分按模式、版本及難度分開保存，每次得分即更新，重玩不會清空最高紀錄。完成回合另外保存星星、準確率及歷史紀錄。

每次送出錯碼，或在 RPG 戰鬥中超時，立即加入錯字簿；同字不重複開卡，會累計錯誤次數。結算顯示本局打錯的字、送出的碼、超時紀錄及正確取碼，即使後來答對仍保留本局回顧。

每個錯字在任意練習／挑戰中累計答對兩次後移除，無需連續答對，途中再錯不會抹去已累積的掌握次數。可從錯字簿開始專項練習。資料保存在目前瀏覽器 localStorage，三代、五代、符號及輔助字形分開記錄；未提供雲端同步。

## 標點符號

依用戶提供的 `data/punctuation-user-reference.json` 完整收錄 75 筆 ZX 符號碼，逐筆保留符號和原表字根標示（包含 Z、戶、甘）。同形異碼不合併；點號、細線、全形／小型／直排符號及空白不互換。可按 ZXA／ZXB／ZXC 組篩選及搜尋符號、字碼和原表字根；首頁查碼亦會列出同符號的全部字碼；點選單列即可練習指定字碼。空白以 ␠ 顯示，仍輸入 ZXAA 後按空白鍵送出。符號錯字依字碼分開記錄，同一符號的不同碼須各自答對兩次；舊錯字簿以字碼移轉並保留已累積進度。

## 五千字標色資料與檢查

五代標色庫恰好 10,000 字（原有 116 字＋生成 9,884 字），優先收錄常用字。每個字碼獨立一色，未取碼筆畫留灰；長筆畫可分成多段，例如事、重。龍只將亠取卜，末碼匕的橫畫與豎彎鉤同色；完的厂與乚分開。包及抱、泡等字的內口與彎鉤亦分段標色。

教室支援中文字／倉頡字碼搜尋，每頁 48 字。五代與三代碼不同時，三代不沿用五代標色；教室與抽題只顯示符合當前版本的示範，其他題仍可查看所選版本的正確碼。

`colour-library.js` 由 `scripts/build-colour-library.py` 生成。`data/colour-source.json` 保存已選字與必要部件的原始輪廓、IDS 筆畫對應、字根模板及來源雜湊；`data/colour-audit.json` 保存新增字每一碼的部件來源與筆畫區域。生成不依筆畫數平均切段：先沿 IDS 對應筆畫，再使用明確字根模板，最後按用戶五代碼表選取有效字根；不能唯一定位的跨部件情形不收錄。相鄰重複字根依首／尾取碼位置處理。

重建：`python3 scripts/build-colour-library.py`。檢查：`npm test`。瀏覽器檢查在已安裝 Playwright／Chromium 的環境執行 `node scripts/check-colours-browser.cjs`（先啟動 `npm start`；可用 `COLOUR_TEST_URL` 指定網址，或 `COLOUR_TEST_FILE` 指定獨立 HTML）。它會逐字檢查全部標色步驟、原始輪廓、顏色與裁切區域，並輸出每批 100 字的對照圖至 `dist/colour-review/`。

資料檢查與逐批看圖有助發現錯誤，不等於專家逐字認證。若修正部件模板，應重建整個資料庫並重新檢查受影響字，不能只改字碼讓測試通過。

### 共用部件修正（2026-10-21）

依用戶新參考統一修正隹、門、幺、乍、力、斤及相關字。隹只取亻與右下土；門的 N 只取右上日形以下的豎鉤，上方日形留灰；幺的 V 只取第一撇折；乍採 HS。斤的兩撇屬 H，橫畫屬 M，直豎屬 L；取 ML 時兩撇留灰。力的 S 由交接處右方起標，保留折鉤尾。七、工、乙獨立分別取 JU、MLM、NU，作輔助字形仍分別取 P、M、N。

原始上傳五代檔保持不變；用戶指定的教學修正獨立記錄於 `code_corrections`，套用於執行時答案與標色資料。乍系列的 22 個字逐一與三代參考碼核對，教學模式採同一 HS 取形。最新對照圖見 `dist/本次修正標色對照.png`。

## 網站發佈與效能

執行 `npm run build` 產生 `site/`，為完整靜態網站；可放在 GitHub Pages 子目錄。`.github/workflows/pages.yml` 在 main 更新後測試、建置與部署。若倉庫尚未啟用 Pages，先在 Settings → Pages → Build and deployment 選擇 GitHub Actions。

網站首頁使用小型字形索引，10,317 字筆畫輪廓按需載入 213 組 JSON 資料；116 個初始示例另有一份按需恢復資料。首頁不下載完整 colour-library.js，不依賴外部字體；靜態檔以內容雜湊命名。`npm start` 自動建置，Node 伺服器支援 Brotli／gzip 與快取。原本的單檔 HTML 仍是全字庫離線包，檔案較大；線上網站使用分組版本。

`node scripts/check-site-browser.cjs` 測試首頁不載入字形分組、慢速網路、載入失敗重試、全部字形可載入及 Pages 子目錄。最新測量：150 KB/s、100ms 延遲、4 倍 CPU 降速下，首頁教材可操作約 3.0 秒（此環境測量）。報告存於 `dist/site-performance.json`。

門部更新：依用戶矩形示意圖，右側日形包含右豎均留灰，只有日形以下的豎鉤取 N。共用門模板套用至 41 個標色字，關另有直接模板並同步修正。

小：獨立輸入取 NC，豎鉤為弓、左右兩點為金；尖等字內的小形仍取 F。字根輔助形練習與獨立中文字模型分開判定。

也部件標色：左側伸出的橫段與豎彎鉤歸 P，中豎與右側橫折鉤歸 D。也仍取 PD，池 EPD；共用模板與池的獨立模板同步修正。

又獨立輸入 NK，部件取 E；入獨立輸入 OH，部件取 O。兩種身分的答案與標色模型分開處理。

別的力部筆順與共用力字不同，明確取其右側橫折鉤為 S，撇畫省略。參的末碼 H 只取彡的最後一撇，上兩撇省略；彡模板逐撇辨認，再依整字實際取碼選首尾。

標色修正：態、熊的能部縮碼取最後匕；半的火含上方中豎；覀的 W 只取外框、酉的 W 不取內橫；黃取 TMWC；鳥的日不含下方延伸豎畫，卜只取延伸豎與中橫，下方橫折鉤留灰，鳳等同類字同步修正。匕獨立 UH／部件 P，八獨立 HO／部件 C。

## 字形載入恢復（2026-10-26）

修正標色教室出現大量文字占位與「部分字形未能載入」的問題。已重現同頁一個檔案失敗、另一個成功時，46 字資料已載入卻只畫出 6 字的情況；原本 Promise.all 提前拒絕後沒有重畫成功資料，手動重試又可能繼續請求網站更新前已移除的雜湊檔案。

字形改以 JSON 載入，完整檢查筆畫與標色兩份資料後才一起套用。共用請求佇列最多同時下載 4 個字形檔，每次最多嘗試 3 次，短暫錯誤自動重試，15 秒無回應會中止。失效路徑或不完整內容會重新讀取不使用快取的 `colour-manifest.json`，以目前檔案位置恢復載入；路徑更新另給一次嘗試。若字碼本身已更新，保留進行中的答案並提示重新整理，不混用不同版本的字碼與圖形。

同頁成功的字形即時顯示，僅重試缺少的資料；錯誤提示與重試按鈕移到字格外。網路恢復時會自動再試，離開教室後的延遲回應不會重開舊頁面。初始示例也有恢復資料，避免只有筆畫、缺少標色時被誤判為完成。每次建置清空產物目錄，避免本機殘留舊檔案掩蓋正式部署的失效路徑問題。

可用 `node scripts/check-colour-loading.cjs` 檢查部分失敗即時顯示、手動重試、暫時斷線、網站更新移除舊檔、內容截斷、重新連線、初始示例缺資料、延遲回應與手機版面；`node scripts/check-learning-guidance.cjs` 核對練習與勇者傳的載入期間倒數、重試與離開戰鬥。

驗證：101 項單元測試通過，包含 11 項載入器測試；七種瀏覽器載入情境與手機提示版面通過，原問題中已成功的 46 字現在全部即時畫出。全 10,317 字、41,485 個取碼步驟、125,259 個 SVG 區域檢查通過；正式網站全字庫載入與 Pages 子路徑、四種練習模式、三種勇者傳難度、載入失敗時暫停倒數及離線單檔版本也通過。字形與字碼資料不變。
